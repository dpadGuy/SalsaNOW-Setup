Not on Windows?

Continue in the web app

Install the game and wait for the installation to finish.

Right-click the developer link and choose Open link in new tab.

In the new tab's address bar, paste https://salsa.salsanowfiles.work and press Enter.

Click OK on each error message until File Explorer opens. Then paste the game's full path, including the .exe, into the File name box.

In the game's Steam properties, turn off Steam Cloud and the Steam Overlay, and set the controller override to Disable Steam Input. Now start the game!

When you're finished, shut down your session properly: open the Windows Start menu by clicking the Windows icon or pressing Ctrl + Win, then click Shutdown Session. Done!

Congratulations, you now have SalsaNOW installed!
